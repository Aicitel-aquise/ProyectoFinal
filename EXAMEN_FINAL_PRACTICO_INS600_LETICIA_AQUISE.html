CONDICIONES TÉCNICAS OBLIGATORIAS
  • Lenguaje y base de datos: C# con .NET (ASP.NET Core) y SQL Server. No se acepta otro lenguaje ni otro gestor.
  • Backend como API: Toda la lógica y el acceso a datos están en una API REST que responde en JSON.
  • Frontend separado: Las pantallas se construyen con Vue.js, Angular o React, a elección del estudiante, y obtienen todo de la API con peticiones HTTP. El frontend nunca se conecta directo a la base de datos.
  • Git y GitHub: Todo el proyecto se sube a un repositorio de GitHub, con commits hechos a medida que avanza el trabajo y no uno solo al final.
  • En línea: El sistema debe poder abrirse desde un celular fuera del laboratorio, mediante un túnel como Dev Tunnels, ngrok o Cloudflare Tunnel.
  • Instalador: Al final se entrega un instalador (Setup.exe) generado a partir de la aplicación publicada, que la deja lista para usar en otra computadora.
  • Datos de prueba: Al menos un usuario por cada rol, cinco registros en cada mantenimiento y tres operaciones del proceso central.

A.3 (continuación) Especificación del caso de uso del proceso central
Caso de uso Emitir Hoja de Ruta Diaria Reglamentaria
Actor Controladora de Parada (Irma Calle) / Secretario de Hacienda (Honorato Ticona)
Precondición El vehículo debe estar registrado en el padrón sindical y el usuario debe estar autenticado con su rol.
Flujo básico
(pasos numerados)		 1. El controlador ingresa a la pestaña "Emisión Hojas de Ruta".
2. Selecciona el minibús en el menú desplegable por su placa (id_vehiculo_js).
3. El sistema verifica de inmediato las deudas acumuladas y si ya tiene hoja hoy.
4. El sistema carga automáticamente el aporte reglamentario fijo de Bs 10.00 (monto_aporte_js).
5. El controlador selecciona la condición de pago del chofer: Pagado o Pendiente.
6. Presiona el botón táctil "Emitir Hoja de Ruta".
7. La API valida las reglas de negocio, guarda la hoja en SQL Server y la lista se actualiza en vivo.
Flujo alterno
(un caso)		 Caso A: Bloqueo por Morosidad (RN-03): Si el vehículo acumula 3 o más aportes pendientes, el sistema bloquea la emisión, emite una alarma sonora y despliega una alerta crítica roja con la placa y la cantidad de deudas. El chofer debe cancelar sus aportes pendientes antes de poder recibir su hoja.
Caso B: Emisión Duplicada (RN-02): Si el vehículo ya tiene hoja emitida hoy, el sistema rechaza la petición con código 400 y el mensaje "El vehículo ya tiene su hoja emitida hoy".
Postcondición Se crea el registro en la tabla HojasRuta con ID único autoincremental, el aporte se registra y el vehículo queda autorizado para circular durante la jornada.
